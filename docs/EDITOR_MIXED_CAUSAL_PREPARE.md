## Scope

The existing unbound factory, default preparation controller, classic PLAY and accepted layout remain unchanged. Existing project/master/save and Studio paths are not replaced. No producer-wide playback, timer, native backend or new public port layout is introduced.

## Retire C, R and the source independently

`service_command` and `service_reader` obtain independent genuine proofs. Command detach does not retire readers; reader retirement does not detach the command or close its retained holder. The cache lease and master pin survive until their actual reader/holder consumption. Counts, predictions, a clean callback return or a pending receipt are not substitute lifetime proofs. NULL slot consumption is terminal even when a child simultaneously returns close `0`; do not retry that consumed child.

`cancel`/`close` cancel untransferred factory work and locally stop the unpublished queue. Local cancellation does not service published C/R quiet proofs or force release; those independent lifetimes need explicit services. After actual C/R and queue consumption, close invokes `source_close` once; a later explicit close may invoke `source_quiet` if shutdown remained pending. Neither path fabricates source quiet. Retained readers close before dependent untransferred commands; the pool and holders close before the causal owner. Submitted or uncertain C/R ownership vetoes note edits, undo, routing changes and disposal through the installed hook. Such an edit is a cancellation request, not an inert ownership query.

After C/R and queue consumption, the owner invokes `source_close` once. An unknown/nonpositive outcome retains the owner, hook and callback contexts. A later explicit close attempt may obtain positive read-only `source_quiet`; it must not repeat shutdown. Only actual complete positive consumption permits final hook removal. Release callbacks publish actual child consumption before reentrant user code.
