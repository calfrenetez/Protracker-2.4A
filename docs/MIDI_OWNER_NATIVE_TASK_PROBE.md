# Experimental MIDI owner ordinary-Task RAM probe

`PTMidiRequesterOwnerTaskProbe` is a separate qualification entry. It reuses the
existing durable MIDI setup owner, controller, modal and real chronological
journal. It is excluded from default builds and the native editor. No MIDI Setup
window, frontend dispatch, CAMD/provider, route, clock traffic or musical output
is activated by adding this source. The original HOST selection and default
requester behavior remain unchanged.

Both options must be exactly1:

- `PT_MIDI_SETUP_OWNER_NATIVE_TASK_PROBE_ONLY`
- `PT_MIDI_REQUESTER_OWNER_NATIVE_TASK_PROBE_ONLY`

The real compiler must identify classic m68k Amiga. HOST options, HOST document
composition, AROS and MorphOS are excluded. These options select an experimental
RAM test; they are not general native-owner or application admission. Never fake
platform definitions or remove the original gates to compile another caller.

The bounded lifecycle initializes a real document/editor and independent Fast
owner/modal blocks on one original checked allocator context. It applies actual
input/output metadata, retains an undone redo record, cancels another real draft
without changing save bytes or accounting, then disposes the genuine journal and
positively closes the original controller. Genuine editor initialization at its
final address precedes actual owner rebind. A final clock-field edit is followed
by actual disposal, controller close, once-only workspace release and zero
allocation ledgers. No live owner or journal image is copied or reset.

Original Task/Exec and nesting observations are checked at entry and around real
callbacks.32-bit geometry and every semantic guard are always active. Unexpected
ownership, placement, Task or callback results retain the whole original process
and contexts; there is no retry, forced cleanup, rollback, failure exit or release
certificate. The ordinary C runtime may perform its normal Exec/DOS/stdio work.
The test itself has no device, window, interrupt, filesystem or cache-upload path.

The [relative source recipe](../tools/probe_recipes/midi_requester_owner_task.json)
lists34 explicit units and exact target options. It is descriptive, not an
executable builder, default target, toolchain/SDK admission or deployment path.
Actual source exports, genuine SDK dependencies, tool pins, object/link vectors
and original-input preservation require separate review. Preserve every earlier
failed attempt and historical HOST receipt; a new source hash cannot relabel an
old run.
