# MIDI requester owner/modal composition

The HOST selection in `midi_requester.h` and `midi_requester_model.c` composes
the existing model with its [durable owner](MIDI_SETUP_OWNER.md). It requires
`PT_MIDI_REQUESTER_OWNER_HOST_ONLY=1` and the unchanged HOST-only owner gate,
which rejects native targets. Default requester behavior and ABI stay unchanged.
This adds no controller, output owner, change barrier, CAMD operation or frontend.

The separate [ordinary-Task RAM probe](MIDI_OWNER_NATIVE_TASK_PROBE.md) may select
this same modal body through its paired experimental native options. It opens no
window and does not enable a frontend, device, output or HOST document route.
The historical HOST qualifications below keep their original source bindings.


One stationary, separately owned binding contains the real owner ticket and
transient model. Callback-free admission checks its full extent against the exact
original owner capacity, workspace and allocator context before writes. The caller
also establishes disjoint placement from editor/project/document/PCM, history,
retained records and other live inputs. Original sources and allocator context
stay alive; known spans are not a heap census or universal lifetime identity.

Begin obtains the real exclusive ticket and opens the chooser with its controller
and captured track. Failed open positively returns an acquired ticket once and
clears only the ended transient binding; it may consume a serial without editing
the song. Apply commits one field through the real chronological journal. A
consumed model does not end its committed or undone resource records.

Return cancels a still-live model and matches the original ticket once. Positive
return permits another modal; it grants no controller/history release or quiet.
Callback reentry refuses BUSY. Uncertain refusal or HELD retains the original
domain and binding, without retry/reset/forced cleanup. Existing owner semantics
may end a HELD UI borrow while retaining unresolved ownership. Actual journal
disposal, positive owner close and workspace release or final-address rebind stay
separate operations. Return must precede any document transition.
