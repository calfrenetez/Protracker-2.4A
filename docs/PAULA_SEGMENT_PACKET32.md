# Paula geometry packet32 HOST model

The pure converter records a prepared finite Paula action as 296 explicit big-endian bytes. It preserves the original ticket, half-open timing window, full-width frame and phase values, selected source identities, and INITIAL/REPROGRAM/STOP semantics.

Address and identity values are caller-supplied HOST labels. They do not authenticate a source, establish currentness or describe a real Chip-RAM address. The converter performs no allocation, callbacks, timer programming, queue activation, MMIO, DMA, IRQ handling or ownership retirement. Its header refuses native builds.

The fixture uses the genuine measured sequence producer and actual sampler pins and selective Chip cache leases through the preserved, entry-renamed sequence fixture donor. The donor's dormant test main is never called. Both measured retirement orders are covered by the actual 46-case fixture.

The standalone Python qualifier preserves all 34 strict translation units, 86 pinned source bodies, 141 physical quoted-include edges, the complete 266-byte oracle, assertions, warnings as errors, and AddressSanitizer/UndefinedBehaviorSanitizer checks. Its only changes from the privately qualified driver are the standalone description, repository-local preservation root, and removal of three private admission preconditions.

The separate private and standalone canonical 46-case HOST trials passed with the exact oracle and unchanged strict checks. See PAULA_SEGMENT_PACKET32_ACCEPTANCE.md for the evidence boundaries. This model does not enable native live playback.
