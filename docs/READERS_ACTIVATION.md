# Optional copied activation ledger

This additive opt-in ABI2 backend has one ordinary fixed allocation, two command
records, eight independently retained reader histories and four physical slots.
It is not an editor PLAY route, device backend or native activation qualification.
The reader adapter, song producer and ABI2 interface retain their existing contracts.

Open with a fresh session, original grid and explicitly injected qualified port;
obtain the copied ABI2 backend and give it to one publishing queue/producer. The
first accepted or uncertain publication permanently binds that queue identity.
The genuine song route requires already-current immutable master versions and
uses begin_in_workspace, real opaque setup/audit and its same renderer sequence.
No promotion, owner cast, public validated flag or activation certificate is used.

Publication copies resolved signed8 geometry, all full original keys, the original
absolute frame/window, and all four expected current slot keys. A submitted event
is not ACTIVE. A pending slot-changing batch prevents another publication even
on a disjoint slot; explicit retry is allowed only at the same original frame
while publication is still before its first tick. Control-only pending batches
may coexist while their full current keys remain unchanged. No early/immediate
fallback, catch-up, shifted frame, new epoch or automatic retry exists.

The separately qualified port copies/prepares/arms the whole batch or refuses
without any references/effects. It independently invokes fire inside [first,last).
The ledger compares all original expected slots before effects; the port must
independently compare its actual four-slot registry before its first effect.
A successful commit positively establishes persistent reference adoption and
actual slot state. Returned untouched keys/masks must remain exact. adopted_mask
means adoption of current ACTIVE slots, equals active_mask on success, and says
nothing about old/draining reader references. STOP/replacement preserves those
independent histories until an exact reader_quiet proof.

Activation reads only its copied command/key/geometry records and actual port
clock/commit callbacks. It calls no core queue, traverses no original event,
domain, span vector or holder, and invokes no current/terminal/release callback.
Both pre/post read_clock and commit require separately qualified bounded actual
clock, all-or-none whole-batch behavior, exclusion, callback/context lifetime,
no reentry, and no allocation/conversion/editor/owner traversal. Flags merely
declare these requirements. Partial/unknown/late effects latch failure and keep
possible domains; they never become positive ACTIVE. Native immediate
audio.device and WAITECLOCK adapters are not this port.

Task service guards full retained resource spans, command/reader bindings,
registered descriptors and original full span metadata-vector extents. Immutable
live registered storage remains valid through its stated borrow; no test may
poison/free it to prove traversal absence. Only ended caller declarations and
construction scratch may be discarded. Known returned allocation aliases are
not released as fresh ownership; unenumerated opaque contexts stay a caller
responsibility. All entries and port calls are externally serialized; busy
failure is not a lock or a concurrent-call implementation.

COMMAND_DETACHED and READER_RETIRED are independent proofs. Detachment removes
all named command callback/packet references, without inferring sample retirement.
Retirement removes all named reader/sample/holder references without inferring
command detachment. Completed/cancelled command packets discard sample addresses.
Cancelling an old full key cannot cancel a replacement by slot. DONE produces no
STOP or retirement; explicit terminal STOP keeps the original terminal frame.

For shutdown first drain independent domains, close EVERY core queue containing
the copied API (including an empty queue), and end every possible autonomous port
callback source. Then close the ledger, then its contexts/source. ABI2 has no
queue-close notification: zero held counts alone cannot enforce this order. Close
never polls, cancels, sends STOP or force-unpins. Final release consumes a genuine
live typed handle; observable release reentry returns failure after consumption.

independently detached. For a never-issued TRIGGER, the cancelled command retains

separate reader receipt retains RETIRED. The command-only validator accepts that
exact combination only when the genuine reader is already valid, retired,
unadopted and untimed. It never revives the reader, infers command quiet from
reader quiet, or releases storage while a referencing command remains.
