# Explicit quantized levels in the genuine sampler factory

`pt_sampler_mixed_begin_quantized` adds an explicit opt-in batch to the existing genuine sampler factory. The legacy `pt_sampler_mixed_begin` request and queue contracts remain unchanged. This extension copies already quantized `uint16_t` left/right register levels; it does not accept raw plans or Q16 gains and supplies no controller/normalizer facade or whole-song producer.

The complete fixed batch has 16 action slots and 16 level records; count is 1–16. A level tag is `LEGACY` or `QUANTIZED`. Active and unused LEGACY records require zero left/right fields. Unused actions require all declared fields zero; inactive union fields are checked canonically rather than by padding bytes. QUANTIZED is valid only on an AmiGUS TRIGGER, with nested legacy volume/pan zero. Any uint16 pair, including zero/zero, is valid. Paula, CONTROL and STOP require LEGACY/zero/zero. Unsupported or ambiguous fields refuse before allocation, entry writes or callbacks.
