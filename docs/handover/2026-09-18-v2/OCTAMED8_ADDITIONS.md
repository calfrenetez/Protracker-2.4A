# OctaMED 8/8.1-inspired additions

These are now incorporated into `FINAL_SCOPE_2.4G.md` and are required:

1. **Recent Projects** — ProTracker-style Disk Op list of roughly the last 10 songs/projects.
2. **Explicit MIDI OFF event** — pattern-level Note Off, including live-recorded key releases.
3. **CAMD endpoint selection** — selectable MIDI input/output devices/clusters with graceful missing-device handling.

No other OctaMED 8/8.1 feature is added merely by association.
