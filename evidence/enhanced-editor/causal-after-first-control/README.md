# After-first playback CONTROL: scoped software qualification

An optional internal owner mode can publish one numerical CONTROL after a
genuinely completed first TRIGGER. It changes Paula period/volume or AmiGUS
rate/levels while retaining the existing reader, master version, cache lease and
sample geometry. Admission derives target keys internally and requires positive
queue ACTIVE observations. The original absolute frame/window remains in force.

The separate capability must be installed once on an empty owner with the exact
original port context. Its port independently verifies its own first completion
and complete twenty-slot registry. Command, reader and source quiet proofs stay
independent; cancellation and uncertain callbacks retain the required ownership.
The default prepublished two-TRIGGER API and its accepted fixtures are unchanged.

`candidate.json` pins the four adopted source/test paths. The new 34-case fixture
and unchanged default 26-case fixture passed strict C99 ASAN/UBSAN builds against
freeze02. Eight affected publication/factory/controller/song/RAM software groups
passed freeze01; their exact scope is retained in `host-results.json`. Freeze02
changes six representation-checked copies to `memcpy`; its later header change
only clarifies refusal versus detected exclusion faults. Tested/final header
identities are disclosed in `implementation-results.json`. Root independently
checked all ten saved group results, full oracles, empty compiler/runtime stderr
and equal before/after dependency hashes. Earlier failed HOST attempts remain
in `preserved-attempts.json` and the original numbered workspace logs.

The fixture covers 8/16/24-bit masters, 8/16-bit card caches, disposed and poisoned
first command storage, target-only ACTIVE observations, unchanged cache/upload/
allocation counts, expected-only cancellation, partial/zero/unknown callbacks,
late/malformed results, aliases, detected reentry and genuine enqueue transfer.
Each lifetime preserves the original master/project beforeimage. `REVIEW.md`
records the independent source review and resolved copy-portability finding.

The exact final C/header also passed strict pinned m68k compiler-only checks;
`compiler-only.json` records commands/dependencies and the 24,188-byte object.
`stack-usage.txt` contains local compiler annotations, including the task-only
CONTROL enqueue frame. These establish neither aggregate task/IRQ stack bounds
nor a linked or running native candidate.

The normal adopted repository driver is:

```sh
python3 -B tests/test_mixed_readers_causal_control.py
```

Its separately recorded integration result is `repo-driver.json`. Shared targets
were not touched by this work. Amiberry and real-A1200 execution are **NOT RUN**;
native preparation/exclusion/timer aperture, exact live timing, WCET, DMA/card
ordering/completion/voice-stop, audio and listening remain unqualified. The
producer/controller/native port still support their existing two-TRIGGER path.
This addition provides neither prepublished CONTROL, musical STOP, third command,
rolling refill nor default/classic PLAY integration.
