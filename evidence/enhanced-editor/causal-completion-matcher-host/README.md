# Causal completion matcher: accepted HOST qualification

The accepted V5 operation compiled 80 genuine units with assertions, ASan and
UBSan. Its complete output contains the existing 34-case RAM fixture and two
additional cases with 219 matcher checks. Both command streams and the full
842-byte oracle passed; compiler 19.392s, runtime 0.675s and outer 22.220s stayed
within the separate 120/30/240-second bounds. The public process was reaped and
its original group was absent before exact owned source cleanup.

The added cases retain the actual first-completion tombstone after poisoning
and freeing the first command, retain its independent reader and successor,
and reject forged identities, windows, observed/issued ticks, serials, masks
and all twenty keys. Successful and refused comparisons preserve the owner,
port and request. The task diagnostic remains a separate task-side API.

The enclosing V1 through V4 failures remain preserved in the private project
outputs. V5's private workspace passed strict metadata and byte custody;
that result does not identify the cause of the earlier refusals. No failure
has been relabelled as a pass.

`raw/` contains all six complete streams, including the empty files. The two
receipts and independent saved audit are exact durable copies. `observations.json`
binds these copies; `copy-manifest.json` preserves their original private paths,
identities, modes and hashes. Copying evidence is not another test invocation.

This qualifies host software behavior only. Native ABI, interrupt entry, stack,
WCET and deadline aperture, Amiberry, real A1200, device transfer/stop, audio and
listening remain unqualified for this change. See
[the source contract](../../../docs/CAUSAL_COMPLETION_MATCHER.md).
