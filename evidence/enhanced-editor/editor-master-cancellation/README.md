# Optional editor master-preparation cancellation

The opt-in `editor_mixed_establish` adapter adopts the existing cancellable
all-slot master establishment job through the actual editor mixed change barrier.
An edit or disposal cancels the source borrow before mutation; an unfinished
unpublished copy is discarded and completed 8/16/24-bit masters stay sampler-owned.
Allocator reentry vetoes mutation and retains the adapter until a later explicit
stop. Metadata and master returns protect the entire controller, editor, binding,
parent vector and explicitly named opaque contexts before initialization.

The legacy binding retains its original link closure when the new adapter is not
used. No existing UI/native PLAY path is installed. READY requires confirmed stop
before downstream engine binding or checked owner construction. Integration of
that checked owner through both drains, timer clearance and zero-child finish is
still separate work. This does not make synchronous legacy bridge binding
cancellable, alter the exact musical schedule or qualify device output.
