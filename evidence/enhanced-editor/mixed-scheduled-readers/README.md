# Typed paired scheduled readers: saved host evidence

The new optional core queue gives Paula and AmiGUS one typed whole-batch
publication and immutable original clock window. It bounds two commands,
sixteen actions per batch and thirty-two persistent reader histories, with
unique route/slot and complete original keys. It does not widen Paula ABI2 or
cast prepared owners. The [contract](../../../docs/MIXED_SCHEDULED_READERS.md)
describes geometry, admission and caller lifetimes.

Genuine independent holders retain each master and selective Chip/card cache
after upload temporary-pin completion. Command detachment and per-reader
retirement are distinct proofs; zero command references are also required before
a reader releases. Actual accepted/refused/uncertain effects are preserved after
failure. An issued command with unadopted readers gives no key, CONTROL or STOP
authority; a separate actual ADOPTED+ACTIVE proof can grant it. Unknown, partial
or stale classifications do not invent activity or quiet. Exact independent
quiet proofs can drain their own domains after failure through explicit NULL
outputs, with invalid classification reported as terminal `valid=0`.

The final current HOST_ONLY qualifier is `attempt-oxjh_ms9`, preserved in
`current/`: four ASan/UBSan compile/run calls pass, all return codes are zero and
all four stderr files are empty. The 923 frozen byte/mode inputs are 918 committed
baseline source/test files from `c6783d79ea679bdc8acff3d38ee1c66f1564c9ed`, exactly
four additive overlays, and the generated font. Protected working changes were
not adopted. The runner confirmed unchanged HEAD, Git index and sixteen
protected working-file fingerprints. The root current controls and independent
final read-only review bind the exact source files, run, complete inventory and
protected controls. The review reports PASS with no concrete blocker.

New assertions pass twelve genuine sixteen-action lifetimes across 8/16/24-bit
masters and 8/16-bit card caches, twenty constructor admissions, 180 typed input
admissions, 78 callback/effect/proof cases, 24 explicit clock/refusal/pending/
cancellation groups, six malformed-reader envelopes, eighteen endian/loop/
nonzero-padding groups and six full alias/capacity/replacement/CONTROL/STOP
groups. Tests use real committed sampler pins, selective Chip leases and AmiGUS
reservation/cache/upload model bodies. Literal clock and conversion oracles,
exact master-preserving saves and inherited Paula ABI2 regressions pass. Actual
callbacks and hook consumption are asserted, including new-holder output alias
refusal before reentry faults, low-budget refusal before constructor faults,
issued/unadopted pins followed by separate actual adoption, expired construction

One explicit publication reads the original clock once and attempts at most one
whole-batch submit; each domain service performs at most one corresponding
callback. Valid clock observations detect regressions even after confirmed
refusal. Local stop drops only unpublished work. There is no two-route immediate
submit wrapper, timer opening/service, automatic retry, rebasing, catch-up,
musical STOP, forced release or native UI/PLAY/display/event-loop integration.
Capability flags declare a backend contract; the queue cannot qualify actual
paired atomicity or genuine holder provenance from public records alone.
