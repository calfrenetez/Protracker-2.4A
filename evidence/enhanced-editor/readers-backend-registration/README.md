# Public backend registration: saved qualification

Separately compiled readers backends can now obtain the opaque command and reader
identities required for exact release receipts through public descriptors. The
opt-in descriptor ABI is version2; numeric version1 is refused before allocation
or callbacks. No owner callbacks or access to owner storage are exposed. The core
retains the original exact frame, private-envelope and independent release rules.

Before reporting command detachment or reader retirement, a backend must drop all
corresponding references. Core reader storage separately waits for independently
exact retirement and zero referencing commands. Command metadata cannot revive a
retired reader. See the [contract](../../../docs/READERS_BACKEND_REGISTRATION.md)
and [architecture](../../../docs/SAMPLE_MEMORY.md).
